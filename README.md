# 📋 Kanban Board

A simple and interactive **Kanban Board** built using **HTML, CSS, and JavaScript**.

This project allows users to create, manage, delete, and move tasks between different columns using **Drag & Drop**. Tasks are stored in **LocalStorage**, so the data remains available even after refreshing the page.

## 🚀 Features

- ➕ Add new tasks
- 🗑️ Delete tasks
- 🖱️ Drag & Drop tasks between columns
- 💾 Persist tasks using LocalStorage
- 🔄 Data remains after page refresh
- 📱 Simple and responsive UI
- ⚡ Built with Vanilla JavaScript

## 🛠️ Tech Stack

- **HTML5** – Structure
- **CSS3** – Styling and layout
- **JavaScript** – Functionality and DOM manipulation
- **LocalStorage** – Persistent task storage
